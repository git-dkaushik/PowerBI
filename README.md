# PowerBI
## Blinkit Sales Analysis Dashboard

Power BI dashboard analyzing Blinkit sales across outlets, item categories, and locations.

Key Metrics


Total Sales: 1.20M
Avg Sales: 141
Avg Rating: 3.9
Items: 8,523


Features


Filters: Outlet Location Type, Outlet Size, Item Type
Fat Content: Low Fat vs Regular, by sales and outlet tier
Item Type: Sales ranked by category, toggle across Total Sales / Avg Sales / No. of Items / Avg Rating
Outlet Establishment Trend: Sales by year (2012–2022)
Sales by Outlet Size & Location: Tier 1/2/3 breakdown
Outlet Type Table: Total Sales, Avg Sales, Avg Rating, Item Visibility by outlet type
